# macropad

Keyboard definition and Vial keymap for Vial-QMK. These files are not a
standalone firmware tree.

To build, place this repository's contents in `keyboards/leighplank` in a
configured [Vial-QMK](https://github.com/vial-kb/vial-qmk) checkout, then run
from the checkout root:

```sh
qmk compile -kb macropad -km vial
```

The original checkout was based on Vial-QMK commit
`fcd56b119ea8c60142c9a03e997be5a7acba52b7`.
